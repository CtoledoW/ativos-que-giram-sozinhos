# Ativos que giram sozinhos

Caixa no curto. Domínio no médio. Império no longo.

## Tráfego é combustível, o motor é o ecossistema

O anúncio só abastece. O que gera dinheiro é o motor: o conjunto de produtos, funis e relacionamento por trás. Sem motor, mais combustível só queima mais rápido.

## A escada Info + SaaS

Comunidade → infoproduto → ferramenta que resolve a dor → assinatura

Quem já consome seu conteúdo é o primeiro cliente da sua ferramenta. Assinatura significa receita recorrente, margem maior e retenção maior.

## Os 3 horizontes

| Horizonte | Foco | Exemplos |
|---|---|---|
| 1. Curto prazo | Caixa | vendas diretas, X1, oferta simples |
| 2. Médio prazo | Domínio | audiência, autoridade, funil rodando |
| 3. Longo prazo | Império | ativos, recorrência, equity |

## Perguntas pra você responder hoje

1. Qual dos 3 horizontes está pagando suas contas agora?
2. O que você faz hoje que poderia virar um ativo (algo que vende sem você estar presente)?
3. Qual problema do seu público se repete todo mês? Ele pode virar uma assinatura?
